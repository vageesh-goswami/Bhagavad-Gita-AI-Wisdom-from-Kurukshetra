# Knowledge-base notes

`gita_knowledge_base.txt` is a small, curated demonstration corpus. Entries are
separated by `---` and labelled with a Bhagavad Gita reference, topics, Sanskrit
text, Hindi meaning, English meaning, and practical themes.

This corpus is intentionally compact so the project starts quickly during a live
demonstration. It is **not a complete critical edition or scholarly translation**.
For a production or academic application, replace it with a verified licensed text,
retain edition/translator metadata, and add citation-level evaluation.
